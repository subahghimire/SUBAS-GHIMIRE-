Admin & Security Center

सुरक्षा जाँच सूची र admin shortcuts। वास्तविक login, roles र server-side access control का लागि backend configuration आवश्यक हुन्छ; यो पेजले आफैँ authentication थप्दैन।

Security checklist

  • Vercel मा ADMIN_CODE र ADMIN_SECRET environment variables राख्नुहोस्
  • Secrets chat वा सार्वजनिक repository मा नराख्नुहोस्
  • Admin API मा server-side authentication र rate limiting जाँच्नुहोस्
  • HTTPS र dependency updates जाँच्नुहोस्
  • महत्त्वपूर्ण फाइलको backup छुट्टै राख्नुहोस्

कुनै पनि secret यहाँ नलेख्नुहोस्।
